# ExplainerIQ Coming Soon

Public, static project landing page for ExplainerIQ. This repository is separate from the local Next.js creator workspace. It contains no application APIs, credentials, user data, database, tracking, or account login.

The copy describes a platform in development. It does not claim approved Google Trends API access or production availability.

Deploy the repository root to Vercel with the Other framework preset, no build command, and the root as the output directory. The production deployment must be publicly accessible without Vercel authentication. Publish with `vercel --prod` after authenticating with `vercel login`.

Only `index.html`, `styles.css`, `favicon.svg`, and `vercel.json` are required for hosting. All assets are self-hosted. No installation or framework build is needed.
